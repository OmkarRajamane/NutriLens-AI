# NutriLens AI

AI-Based Food & Nutrition Estimator

## Overview

NutriLens AI is an AI-based application that analyzes food images and estimates nutritional information such as calories, protein, carbohydrates, and fats.

## Features

- Image-based food analysis
- AI-based food detection
- Food quantity estimation
- Nutrition estimation
- Simple and interactive interface

## 🛠 Tech Stack

- Python
- Flask
- Python-dotenv
- HTML
- CSS
- JavaScript
- Groq Vision API

## How to Run

1. Clone the repository.

2. Install dependencies:

```bash
pip install -r requirements.txt
```

3. Add your Groq API key to the `.env` file:

```env
GROQ_API_KEY=your_api_key_here
```

4. Run the application:

```bash
python app.py
```

5. Open `http://127.0.0.1:5000` in your browser.
